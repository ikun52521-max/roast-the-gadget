One original line roasting the phone I use every day — the gadget that judges my screen time back at me, weekly, with charts. Written for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty. `main.py` prints the line and writes it to `/output/entry.txt` (165 characters, one line, deterministic).

## Run it

```sh
python3 main.py
```
